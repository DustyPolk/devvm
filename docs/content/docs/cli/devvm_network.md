Show or change the network policy of this folder's VM

## Synopsis

Show the network policy of this folder's VM: on, off, or unenforced (on, but not confined: started outside devvm, or before it was turned on). devvm network on or off changes it from the VM's next start: devvm restart. Tokens the VM got while it was off still work once it's on.

```text
devvm network [on|off] [flags]
```
