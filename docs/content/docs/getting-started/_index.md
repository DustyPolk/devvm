These pages take you from installing devvm to working in your first VM.

- [Installing](install.md): what devvm needs on your machine, how to install it with Homebrew or the install script, how to check it with `devvm doctor`, and how to upgrade and uninstall it.
- [Your first VM](first-vm.md): making a VM for a project folder, working on a clone instead, what's in the VM, and coming back to it later.
- [Everyday commands](commands.md): the commands you use most, in the order you'll need them, with the options for a new VM.
